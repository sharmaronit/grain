# Archived files

`archive/landing/` preserves the previous website components, effects, styles,
template documentation, sample logos, and old screenshots. They are outside the
active website source and public assets.

`archive/tools/` contains the historical screenshot capture scripts. Their
original selectors and machine-specific paths are preserved for reference.

Current app screenshot references live in `assets/reference/screenshots/`;
production website copies live in `landing/public/screenshots/`.

Shared reference photographs are in `assets/reference/`. Runtime photographs
remain in each application's `public/` directory so their URLs stay stable.

The unused root Firebase configuration copy is stored under `config/firebase/`
and remains ignored. The Android project uses its own configuration in
`android/app/google-services.json`.
